# xtask_workflow

> English version: [README.md](README.md)

`xtask_workflow` は、リポジトリ内の `cargo xtask` crate 向けに、依存順で実行するワークフローの基本機能を提供します。

この crate は WRAC、オーディオプラグイン、プラグイン形式、ビルドコマンドを意識しません。製品リポジトリは独自のタスク enum、タスクラベル、タスク実行器、依存グラフを定義し、この crate の安定したトポロジカル順序、循環検出、タスク ID、タスク状態、失敗ポリシー、dry-run 出力、依存失敗によるブロック、結果の要約を再利用します。

実行器は呼び出し元が指定するラベルと実行のクロージャーを受け取ります。クロージャーはグラフのノードに保存されないため、タスクの意味は各リポジトリ内のタスク enum から把握できます。

実行クロージャーは `TaskOutcome` を返します。`Completed` は実行した作業を記録し、`Skipped { reason }` は作業が不要だったという正常な判断を記録します。スキップされたタスクも有効な依存先です。依存先の失敗によって実行できないタスクは `Blocked` として別に報告されます。
